# Trustworthy SLM Agent

A reproducible pipeline for fine-tuning a small language model, wrapping it as
a retrieval-grounded agent, and auditing it for hallucination and bias before
generating an automated model card.

**Status:** 🚧 In progress — Phase 1 (data preparation) complete

## Setup (Windows / VS Code)
1. Clone this repo
2. `python -m venv venv`
3. `.\venv\Scripts\Activate.ps1`
4. `pip install -r requirements.txt`
5. See `notebooks/01_finetune_colab.ipynb` for fine-tuning on free Colab GPU
